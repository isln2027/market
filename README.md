# Описание
Веб-приложение представляет собой витрину товаров, которые пользователь может положить в корзину и купить.
Состоит из двух сервисов - основной сервис магазина и сервис оплаты
## Магазин
Основное приложение доступно на порту 8080.
По адресу `/` расположена главная страница, откуда доступны каталог товаров и остальные функции.
Панель администратора для добавления товаров доступна по пути `/items/management`.
## Оплата
Сервис оплаты имеет одну доступную страницу на порту `8081` - `/admin/balance`. 
С помощью нее можно проверить текущий баланс и установить новое значение.

# Сборка и запуск
Приложени рассчитаны на работу внутри docker контейнеров. 
У контейнеров дложен быть доступ к бд и redis параметры подключения к которым передаются в приложение через переменные окружения.

## Сборка образа
Образы основного приложения и сервиса оплаты собираются из корневой директории проекта командами
`docker build -f market-app/Dockerfile -t market-app .` и `docker build -f payment-service/Dockerfile -t payment-service .`
соответственно.

## Запуск
Для запуcка в контейнере можно использовать готовый  `docker-compose.yml` из корневой директории.
Скрипт `rebuid-run.sh` выполняет сборку и запуск приложений в контейнерах.
После старта основная страница доступна по адресу http://localhost:8080/
При запуске с профилем `production` (существующий docker-compose устанавливает этот профиль) база данных 
приложения заполняется при его старте.

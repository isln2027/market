# Описание
Веб-приложение представляет собой витрину товаров, которые пользователь может положить в корзину и купить.

# Сборка и запуск
Приложение рассчитано на работу внутри docker контейнера. 
У контейнера дложен быть доступ к бд, параметры подключения к которой передаются в приложение через переменные окружения.

## Сборка образа
Образ приложения собирается из корневой директории проекта командой `docker build -t market .`

## Запуск
Для запуcка в контейнере можно использовать готовый  `docker-compose.yml` из корневой директории.
Скрипт `rebuid-run.sh` выполняет сборку и запуск приложения в контейнере.
После старта приложение доступно по адресу http://localhost:8080/
При запуске с профилем `production` (существующий docker-compose устанавливает этот профиль) база данных 
приложения заполняется при его старте.
